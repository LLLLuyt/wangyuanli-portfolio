## 使用建议（与网站板块对应）

- **教育背景主视觉** → `cardiff-main-entrance.jpg`（辨识度最高，"Welcome to Cardiff University" 直给）
- **"毗邻 BBC" 佐证** → `bbc-cymru-wales-hq.jpg`（JOMEC 最大卖点：2 Central Square 与 BBC Cymru Wales 隔街）
- **学习/学术氛围** → `cardiff-science-library.jpg`
- **学位与仪式感** → `cardiff-graduation.jpg`
- **城市与校园环境** → `cathays-park-view.jpg` / `cathays-park-aerial.jpg`
- **历史纵深** → `Cardiff-JOMEC-ButeBuilding.jpg` + `cathays-park-campus.jpg`（旧址 → 新址的迁移叙事）
- **说明**：以上均为**环境素材**，用于烘托海外背景；**不要**表述为"我在其中"的照片，避免与个人经历混同。

## 另：视频可补充动态海外素材
卡迪夫大学官方 YouTube 频道与官网有可嵌入的宣传视频，但**版权归属校方**，求职作品集引用需保留来源标注；
更稳妥的做法是用她本人拍摄的英国素材（《风暴后的海堤》等成片抽帧），零版权风险。
